##  Como Executar Localmente

1. Clone o repositório:
```bash
git clone https://github.com/Thiiagoramos/Industria4-0.git
```

2. Abra o arquivo `index.html` no navegador — sem dependências ou instalação.

---

##  Contexto Acadêmico

Projeto desenvolvido como atividade universitária com o objetivo de explorar e comunicar os conceitos fundamentais da quarta revolução industrial, incluindo IoT, automação, IA e manufatura avançada.
O projeto também foi desenvolvido com a finalidade de colocar em prática os conhecimentos em **Desenvolvimento Web** aprendidos na matéria da universidade.
